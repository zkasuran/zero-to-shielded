# How every episode is built

Use the kit in `tools/video-kit/` (Python, Pillow, ffmpeg, Kokoro, Playwright Chromium).
Read `tools/video-kit/README.md` and `tools/video-kit/docs/project-file.md` first.
Its tests must stay green: `cd tools/video-kit && python3 -m pytest -q tests`.

Setup on a fresh machine:

```bash
sudo apt-get install -y ffmpeg fonts-dejavu      # or the platform equivalent
pip install pillow==11.3.0 edge-tts==7.2.3 playwright==1.55.0 pytest==8.4.2
python3 -m playwright install --with-deps chromium
```

(If a pinned version is unavailable, pin the nearest available one exactly and note it.)

## Build order per episode

```bash
cd tools/video-kit
python3 scaffold.py zts-e1 ../../site "Install Zodl and back up your phrase." --template walkthrough
# edit projects/zts-e1.json: replace the template middle with this episode's real scenes
python3 preflight.py projects/zts-*.json
python3 frame.py projects/zts-e1.json 10 40 70      # look at the frames
MUSIC=<licensed track> python3 build.py projects/zts-e1.json
python3 upload.py projects/zts-e1.json
cp out/zts-e1.mp4 ../../episodes/E1-wallet-setup/DEMO-E1.mp4
```

Project files live in `episodes/E<n>-<slug>/zts-e<n>.json` (copy into the kit's
`projects/` to build or symlink). Every episode keeps a `BRIEF.md` beside it: scene
table with real in/out times, full narration cue list, every on-screen string verbatim,
the honesty framing, the gates and their measured results.

## The look (one theme for the whole series)

- One series palette, **Zcash gold on deep ink**: add a palette named `shield` to
  `tools/video-kit/theme.py` PALETTES (radial field, gold accent dark enough for AA on
  the near-white panel, pale gold marker). All six episodes share it so they read as a
  series. Episode number and title on a consistent opening card.
- Thumbnails: same family, one layout per episode, episode number large, readable at
  168px wide. Generated by `thumb.py`, never a frame grab.
- Format: 1920x1080 master. Also export a 1080x1350 (4:5) crop for X if time allows,
  because 4:5 takes more of the feed on mobile.

## Scene rules

- Wallet steps use `device` scenes (phone frame) fed by real clips from `footage/clean/`.
- Concepts (transparent vs shielded, what the chain sees) use `diagram` / `card` /
  `compose` scenes. Label diagrams.
- Every episode has at least one `web` scene captured from the **live** companion site
  URL, with the URL on screen as text, so viewers can type it.
- Every narration cue that names a button or a field uses `focus` on it, so zoom,
  highlighter and cursor land on what is spoken.
- Captions burned in (beginners watch muted on X) and also exported as `captions.srt`.

## Narration

- Voice: Kokoro-82M `af_heart` (Apache-2.0), one voice for the whole series. Rate `-20%`.
  edge-tts is no longer used: its audio has no quotable grant (docs/FACTS.md, Licence quotes).
- ~140 words per minute. A 2:00 episode is ~260 words. Count before building.
- Every episode opens with the outcome ("By the end of this video you will have...")
  and closes with the next step and the site URL.

## Music

Required, ducked under the voice (sidechain), fades in and out. Only a track whose
licence sentence is quoted in `DATA-SOURCES.md` (CC0 or an explicit "free for commercial
use, no attribution required" grant). If none can be quoted, render without music and
write `MUSIC: pending` in the brief; the lead will re-run `AUDIO_ONLY=1` locally with the
house track.

## Gates (every episode, all must pass, results written into BRIEF.md)

- `ffprobe`: duration <= 140 s (X free cap 2:20), video + audio streams present
- loudness: -16 LUFS integrated +-1, true peak < -1.5 dBTP, measured on the final file
- music present (build log names the track) or `MUSIC: pending` recorded
- captions: cue count matches project, last out-time inside duration, no cue < 0.8 s
- chapters: start 0:00, >= 3, each >= 10 s, ascending
- voice gate clean on narration, captions, description
- a frame pulled at each climax and looked at; no recovery phrase, no full balance,
  no unblurred personal data visible
- the `web` scene URL fetched anonymously returns 200
