## Deploy steps

```bash
git clone https://github.com/zkasuran/zero-to-shielded.git && cd zero-to-shielded
git fetch origin media-renders
git worktree add ../zts-media origin/media-renders
mkdir -p ../zts-masters
for n in 0 1 2 3 4 5; do cat ../zts-media/E$n/DEMO-E$n.mp4.part-* > ../zts-masters/DEMO-E$n.mp4; done
cp ../zts-media/SHA256SUMS ../zts-masters/ && (cd ../zts-masters && sha256sum -c SHA256SUMS)

# The masters are about 360 MB each. Make light web copies for the site player.
for n in 0 1 2 3 4 5; do
  ffmpeg -y -i ../zts-masters/DEMO-E$n.mp4 -c:v libx264 -preset slow -crf 23 -pix_fmt yuv420p \
    -c:a aac -b:a 160k -movflags +faststart site/media/zts-e$n.mp4
done

node site/tools/build.mjs && node --test site/test/
cd site && npx vercel@62.2.0 --prod --yes --token "$VERCEL_TOKEN"
```

The Vercel project must be named `zero-to-shielded` so the address is exactly https://zero-to-shielded.vercel.app (see `site/README-DEPLOY.md`). Then check `curl -sI https://zero-to-shielded.vercel.app/episodes/e1/` and `curl -sI https://zero-to-shielded.vercel.app/media/zts-e1.mp4` both return 200. The root `.gitignore` ignores `*.mp4`, so a Git-connected deploy would ship pages without videos: keep deploying with the CLI or switch to YouTube ids.
